Zorua keeps your Codex CLI and Claude Code accounts apart. Works in zsh, bash and fish. Every account gets its own CODEX_HOME or CLAUDE_CONFIG_DIR, so four panes can run four sign-ins at once. No daemon, no proxy, nothing to restart.

features

  • parallel — selection is an env var; no global active account to flip
  • bind on cd — zorua bind work and the repo switches automatically
  • usage — one-line-per-account board with 5h/7d bars; -v for details and credits
  • Codex and Claude Code — zorua add --claude alt gives a Claude subscription its own CLAUDE_CONFIG_DIR; one table, one set of commands
  • any shell — zsh, bash and fish, same commands and the same auto-switch on cd
  • zero deps — Python 3.8+ standard library only, nothing to pip install

quick start

$ zorua add work          # new CODEX_HOME + sign in
$ zorua use work          # this shell only
$ zorua work exec "explain this repo"
$ zorua bind work         # auto-switch in this directory
