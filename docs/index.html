CodeX Switch

Parallel multi-account manager for the OpenAI Codex CLI. Every account gets its own CODEX_HOME, so you can run different accounts in different terminals at the same time.

curl -fsSL https://raw.githubusercontent.com/szupzj18/codex-switch/main/install.sh | zsh

Why

Truly parallel

One account per terminal or tmux pane. No global "active account" that flips every other window.

Project bindings

cx bind work in a repo; entering the directory switches automatically, leaving restores your previous account.

Plans and limits at a glance

cx usage shows each account's plan, expiry, 5h/7d windows and credits, fetched in parallel.

Nothing in the way

One dependency-free zsh script. No wrapper around codex, no daemon, no proxy.

Quick start

cx add work                       # creates ~/.codex-work, runs codex login
cx use work                       # switch this shell
codex                             # ...now runs as work
cx work exec "explain this repo"  # one-shot, without switching

cd ~/code/company-api
cx bind work                      # auto-switch whenever you cd in

Commands

CommandDescription

cx <name> [args]One-shot invocation under that account

How it compares

Global switchSwap auth.json; one active account machine-wideNo
CODEX_HOME isolationOne home directory per account; the shell selects oneYes

cx usage sends each account's own access token to chatgpt.com, the same usage endpoint Codex itself uses. Tokens are never printed or stored elsewhere.
